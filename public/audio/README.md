# Audio Directory

Place your audio file here:
`public/audio/track.mp3` (or `public/audio/gonna-be-better.mp3` or `public/track.mp3`)

When committed to GitHub and deployed on Vercel, the audio player will automatically stream this file on loop for all visitors.

Alternatively, you can set the `VITE_AUDIO_URL` environment variable on Vercel to any publicly hosted direct MP3 URL.
